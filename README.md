# 工作室档期管理小程序

## 首次运行

1. 在微信开发者工具中打开本项目。
2. 确认当前云环境为 `shanli-d7gagpq0537ff1303`。
3. 在左侧 `cloudfunctions/scheduleApi` 上右键，选择“上传并部署：云端安装依赖”。
4. 编译小程序。首次进入首页后点击“导入”，写入三位摄影师的 142 条初始档期。

云函数会尝试自动创建 `schedules` 集合。若控制台提示集合不存在，请在“云开发 → 数据库”中手动新建集合 `schedules`，然后再次点击导入。

## 已实现

- 团队月历、月份切换、回到今天
- 全部/山梨/牧羊/小拐筛选
- 当日档期详情
- 新增、编辑、删除档期
- 同一摄影师同一天唯一校验
- 初始档期幂等导入（重复点击不会重复写入）
